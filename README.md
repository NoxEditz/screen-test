# فحص الشاشة الاحترافي | Screen Test Pro

أداة ويب حديثة وتفاعلية عالية الدقة لفحص الشاشات الجديدة قبل الشراء أو الاستلام، واختبار معدل التحديث الحقيقي، وكشف البكسلات الميتة وتسريب الإضاءة.

## الميزات:
- **كشف البكسلات الميتة والعالقة:** ألوان صلبة بدقة كاملة (أسود، أبيض، أحمر، أخضر، أزرق).
- **فحص تسريب الإضاءة وتوهج IPS:** شاشة سوداء ورمادية معتمة في الغرف المظلمة.
- **اختبار سلاسة الحركة و Ghosting:** أجسام ونصوص متحركة مع تحكم لحظي بالسرعة (FPS + px/s HUD).
- **قياس التردد الحقيقي (Hz Counter):** قياس مباشر لمعدل التحديث وثبات الإطارات مع رسم بياني لحظي لـ Frame Pacing.
- **تدرج الألوان والرمادي (Color Banding):** فحص عمق الألوان واختبار تدرج الرمادي 16 مستوى.
- **أداة تنشيط البكسل العالق:** وميض ألوان سريع لتحفيز البلورات العالقة.
- **تصميم عصري متطور (Cyber Dark Studio):** دعم كامل للغة العربية (RTL)، بدون إعلانات وبدون أي تبعيات خارجية، تعمل 100% بدون إنترنت (Offline).
